# JARVIS 2.0

JARVIS 2.0 is a standalone Windows AI desktop assistant designed to bring a JARVIS-style intelligence layer to your PC. It combines Gemini AI with controlled local PC capabilities, allowing natural-language interaction, file discovery, app launching, and opening files or folders.

## Core capabilities

- 🤖 Gemini-powered AI assistant
- 🔎 Search for files across accessible Windows drives
- 🚀 Find and open installed applications
- 📂 Open specific files and folders
- 💬 Natural-language commands
- 🖥️ Dedicated Windows desktop interface
- 🔐 Local API-key storage
- 🛡️ Limited, explicit PC actions rather than unrestricted shell execution

JARVIS 2.0 is built as a separate companion to the browser-based JARVIS HUD.
